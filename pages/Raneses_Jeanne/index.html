🧸Reflection

Making this page taught me that web design is more than just making things look cute. The code behind it also has to be organized to, especially as someone that cannot function well if things look messy, this aspect of coding is vital in finishing my output.

At first I made a lot of mistakes, such as unclosed tags, image paths written with the wrong slashes, and more. I even made separate HTML files per section because I thought it would make my life easier (it did not haha). This time I combined everything into one page with sections, and I learned that clean, properly closed HTML makes the page easier to fix and easier to style.

I have improved my first activity by adding boxes per section and an inner box per subsection so that it does not look cramped. I also tried using different fonts to enhance the visual aspect of my webpage, as well as using images as my background instead of plain solid colors and changing the opacity to add depth in my design.

What I learned about myself is that I enjoy the creative side of coding, like choosing colors and layouts, and that I can solve problems by testing, fixing mistakes, and asking questions when I'm stuck. This makes me more excited to keep learning so I can reach my goal of becoming a software engineer.
