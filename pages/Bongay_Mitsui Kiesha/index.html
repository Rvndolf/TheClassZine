🪞 Reflection 🪞

What was easy?

Editing and writing the HTML file was definitely the easiest part of the project for me. The basic tags and overall structure of HTML felt straightforward and simple to understand as I built out the layout. Because the core concepts are clear and intuitive so far, I was able to structure the content and table without encountering major difficulties.

What was confusing?

Styling the website using CSS proved to be quite challenging and confusing at first. I struggled with getting the layout, spacing, and overall design elements to align properly on the page. To overcome these, I asked a classmate for assistance and watched several YouTube tutorials to better understand how CSS properties work together. Thankfully, I was able to complete the webpage on time because of their help.

What is one thing I would improve?

Moving forward, I really want to improve my skills and confidence in CSS and web design. Mastering CSS will allow me to build clean, modern, and fully custom layouts from scratch without feeling restricted. By sharpening my design abilities, I hope to unlock limitless creations and fully express my creativity through my web projects.
