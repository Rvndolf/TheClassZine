Reflection

What was easy?

Understanding the semantic structure of HTML was straightforward because elements like header, nav, main, and footer clearly show the layout of a page. Adding headings, lists, and images was quick once I saw how tags open and close.

What was confusing?

CSS layout was the most confusing part, especially how Flexbox alignment behaves on different screen sizes. Adjusting margins, padding, and borders to line up the table with the rest of the content took trial and error.

What would I improve?

I would keep improving the page for mobile devices and add more hover effects. In the future, I would also like to add interactive features once I learn JavaScript.
