Reflection

What did I find easy?

Structuring the HTML. Since HTML doesn't need any programming logic, creating a solid structure for my webpage felt fairly easy. It wasn't too easy, but it was the right kind of easy.

What confused me?

CSS. I was still tripped up on how to organize my selectors, and on which ones to write first or what to tackle first. I still need more practice.

What do I want to improve?

My CSS design. I'm not that bad, but my project could still use work. I would like to learn more about animations and transitions for my portfolio.

Extended reflection

After learning more about HTML and CSS, I realized that the different features in CSS give me the tools to refine my webpage. They let me make more aesthetically pleasing design choices and bake more personality into it, even though it was quite challenging. HTML is more straightforward and easier to learn than CSS, but that doesn't change the fact that it is fundamental for a webpage to exist in the first place. This is where coherency is born.
