Reflection

1. What was easy?

Learning the fundamental structure of HTML turned out to be surprisingly approachable and satisfying. Understanding how markup tags like <h1> for primary headers, <p> for paragraphs, <ul> for lists, and <table> for data grids work together felt very natural, almost like fitting together building blocks to give structure to a canvas. The most rewarding part of this early phase was linking the external style.css file to index.html inside the <head> tag. Seeing my raw text instantly transform into a structured layout with dark backgrounds, red retro borders, and custom Google Fonts every time I saved and refreshed my browser gave me an immediate sense of accomplishment and made the initial setup feel effortless.

2. What was confusing?

As someone stepping into web development as a complete beginner, diving into CSS Flexbox and table alignment was an emotionally overwhelming and frustrating hurdle. I spent hours wrestling with properties like justify-content, align-items, and flex-wrap inside .navbar and .profile-container, trying to understand why elements wouldn't stay in place or why text wrapped awkwardly when resizing the window. as cell paddings and margins kept overlapping unexpectedly. There were moments of genuine self-doubt where I felt stuck and behind, constantly having to pause the tutorial video frame-by-frame and search documentation just to fix a single misplaced line of code. This constant trial-and-error significantly slowed down my pace, but pushing through those moments taught me that feeling confused is simply a natural, necessary stepping stone when building real skills from scratch.

3. What is one thing you would improve?

If I had more time to refine this project, I would love to make the user interface even more immersive and dynamic by introducing JavaScript functionality, such as a custom dark/light mode toggle switch or interactive sound effects inspired by classic Pokémon games. Visually, I would also enhance the responsive design of the interface by adding a dedicated smooth horizontal scrollbar and custom column highlights on mobile screens, ensuring that visitors on smaller devices get an equally seamless and comfortable reading experience without any layout distortion.
