Reflection

While building this webpage, I learned many new HTML elements, CSS rules, and layout styles to try and incorporate. It felt overwhelming at first to grasp everything without a step-by-step guide, so I made a clear layout plan first before maximizing the available elements and styles. Compared to my previous About Me activity, I significantly improved the structure. I placed the main header and navigation on opposite sides, added a full-height sidebar spanning alongside the first three sections, and built four additional sections below them. I replaced the old GIFs with new ones and placed them in the sidebar, so that it will not look not organized. I also experimented heavily with keyframes animations for sliding text, photo tracks, and a gallery carousel. Lastly, I organized the footer by left-aligning my name and credits for the GIFs and background image, while right-aligning the return home button.
