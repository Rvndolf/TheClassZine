WHAT I LEARNED

My Reflection

What was easy?

The easiest part was creating the basic structure of the webpage using HTML. Adding headings, paragraphs, lists, links, and sections helped me organize my information clearly. I also enjoyed choosing my hobbies and writing about my interests because it made the webpage feel more personal.

What was confusing?

The most confusing part was styling and arranging the elements with CSS, especially using Flexbox to make the content line up properly. I had to understand how properties such as display, gap, and align-items affect the layout. Checking the page in the browser and adjusting the styles helped me see how HTML and CSS work together.

What would I improve next?

I would keep refining the design as I learn more about web development, and keep my page organized. I also want to practice writing cleaner code, using comments to explain important parts, and trying more CSS effects while keeping the page easy to read.

What improved since my About Me activity?

Compared with my earlier About Me activity, this page has more sections, a consistent color scheme, a card layout built with Flexbox and Grid, hover effects, and a layout that adapts to phones. I also added a caption and credit to my photo and listed my sources.
